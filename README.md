## 소개

이 저장소에는 방송 진행, 시청자 참여, 화면 연출 등 **치지직 방송에 활용할 수 있는 프로젝트**를 순차적으로 개발 및 배포할 예정입니다.

스트리머가 실제 방송에서 쉽게 사용할 수 있는 도구를 만드는 것을 목표로 하며, 각 프로젝트의 사용 방법과 필요한 설정은 해당 폴더의 README에 따로 정리합니다.

## 예정 분야

- 방송 화면용 오버레이
- 스트리밍 화면을 꾸미는 인터랙티브 콘텐츠
- 스트리밍에서 플레이 할 수 있는 게임

## 이용 방법

1. 위 프로젝트 목록에서 원하는 프로젝트를 선택합니다.
2. 해당 프로젝트 폴더의 README에서 요구 환경과 설치 방법을 확인합니다.
3. 안내에 따라 다운로드하거나 직접 빌드해 사용합니다.

프로젝트마다 지원 환경과 설정 방법이 다를 수 있으니 사용 전에 개별 안내를 확인해 주세요.
