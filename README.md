## 소개

이 저장소에는 방송 진행, 시청자 참여, 화면 연출, 버추얼 무대 등 **스트리밍과 라이브 콘텐츠에 활용할 수 있는 프로젝트**를 모아 배포합니다.

스트리머와 콘텐츠 제작자가 실제 방송에서 쉽게 사용할 수 있는 도구를 만드는 것이 목표입니다. 각 프로젝트는 독립적으로 개발하며, 이 저장소에서는 바로 사용할 수 있는 배포 파일과 버전 정보를 제공합니다.

## 예정 분야

- 방송 화면용 오버레이
- 버추얼 공연 및 라이브 스테이지
- 스트리밍 화면을 꾸미는 인터랙티브 콘텐츠
- 방송에서 함께 플레이할 수 있는 게임

## 이용 방법

1. 위 표에서 원하는 프로젝트의 버전을 선택합니다.
2. ZIP 파일을 내려받아 원하는 위치에 압축을 풉니다.
3. 함께 제공되는 안내 문서에서 실행 환경과 사용 방법을 확인합니다.

프로젝트마다 지원 환경과 설정 방법이 다를 수 있으니 사용 전에 개별 안내를 확인해 주세요.
